# Bingo Garments Product-Only AW26 Preview

Audience: independent apparel brands in North America, Europe, Japan, Korea and Singapore.
Goal: see current garments, inspect images and specifications, select styles and send a useful inquiry.
Direction: quiet product showroom; white, light gray and charcoal with colour supplied by the garments themselves. No AW26 models in the homepage, catalog, product dialog or inquiry list.

Acceptance:

- AW26 appears in the first viewport and the first product section. All 20 styles are discoverable in the new catalog.
- Use all twenty existing supplier garment-only objects. Do not regenerate silhouettes, colours or fabric details. Optimize file delivery only.
- Product-only imagery is primary. Existing model-containing English boards must not remain linked from AW26 details; reference size guides are real HTML tables instead.
- Three-column desktop grid and one-column phone grid; generous image margins, restrained labels, no horizontal page overflow or obscured content.
- Search, category filters, collection tabs, sort, detail dialog, gallery and persistent inquiry selection work.
- Homepage and directory derive collection counts and selections from the same AW26 data.
- Preserve product verification boundaries and quote-only terms. Do not invent specifications, stock, images or prices.
- Keep original CRM form, receipt handling and local-only submit behavior.
- The operator approved website publication on 2026-10-25 after the local preview. No social publishing or outgoing messages.

Scope: homepage and AW26 presentation; existing core catalog, verification controls and quote-only commercial terms remain intact. Website deployment is approved; CRM capture and outbound automation settings must not change.

Flow: Home -> New AW26 -> filter/search -> inspect garment/size guide -> add to inquiry -> review selection -> complete brief -> local saved state.
Empty state: no matching products -> clear filters. Invalid form: browser validation retains the brief.
